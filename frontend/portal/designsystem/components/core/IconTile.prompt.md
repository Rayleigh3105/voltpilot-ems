Gradient-filled icon container — codes a solution by category color. Put an icon/glyph child inside.

```jsx
<IconTile category="solar" size={64}>☀</IconTile>
<IconTile category="ev" shape="circle">🚗</IconTile>
```

Props: `category` (solar/battery/ev/home/industry/dynamic/primary), `size` (px), `shape` (rounded/circle).
