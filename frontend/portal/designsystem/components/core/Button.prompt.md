# Button

Primäre Aktionen verwenden die dunkle Vollfarbe `--vp-action` mit weißer Schrift. Hover, Fokus und gedrückter Zustand stehen in `core.css`.

```jsx
<Button variant="primary" size="md">Speichern</Button>
<Button variant="outline">Details ansehen</Button>
<Button variant="ghost">Abbrechen</Button>
```

Varianten: `primary`, `white`, `outline`, `outline-light`, `ghost`. Größen: `sm`, `md`, `lg`. Weitere Props: `fullWidth`, `disabled`, `iconLeft`, `iconRight` und native Button-Attribute. Icons aus `Icon` verwenden.
