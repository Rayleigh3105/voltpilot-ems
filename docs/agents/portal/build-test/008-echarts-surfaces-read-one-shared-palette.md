# ECharts surfaces read ONE shared palette via src/chartTheme.ts (chartTheme()), never hard-coded hex.

Ausgelagert aus `frontend/portal/AGENTS.md` am 05.09.2026 (Abschnitt Nr. 2, Punkt 008).

- **ECharts surfaces read ONE shared palette via `src/chartTheme.ts` (`chartTheme()`), never hard-coded hex.** Canvas can't resolve `var()` at paint time, so `chartTheme()` reads the `--vp-chart-*` tokens (in `designsystem/tokens/colors.css`) from `:root` once (memoised) with token-value fallbacks. Call it INSIDE the render/`setOption` closure (needs `window`) and map `axis`/`ink`/`grid`/`axisLine`/`pv`/`temp`/`load`/`price`/`soc`/`charge`/`discharge`/`plan`/`cloud`. Re-theming the data surfaces = edit the tokens, not the charts. All charts (`TelemetryChart`/`ScheduleChart`/`PriceChart`/`HistoryChart`/`WeatherChart`/`PriceHistoryChart`/`ForecastQualityChart`) already do this. **Ein Token-Wert lebt an ZWEI Stellen** — in `colors.css`/`index.css` UND als Fallback in `chartTheme()` (für den headless/jsdom-Lauf); beide zusammen ändern, sonst zeichnen Tests und Browser verschiedene Farben.
  - **⚠ Eine Serien-Palette wird IMMER mit `--pairs all` geprüft, nie ohne.** `node scripts/validate_palette.js "<hex,…>" --mode light --pairs all` (dataviz-Skill). Ohne das Flag prüft der Validator nur BENACHBARTE Paare in der übergebenen Reihenfolge — genau so blieb eine Kollision unentdeckt, und genau so kamen die zwei produktiven Kollisionen der Stufe 0b in die Tokens (PV × Temperatur ΔE 6,7 · Batterie-Laden × Netz ΔE 9,8). Die Normalsicht-Untergrenze **ΔE 15 ist ein harter FAIL**, den auch eine Zweitkodierung (Wort/Icon) nicht entschuldigt — die Antwort ist eine andere Farbstufe oder weniger Serien. Geprüft wird die Menge, die WIRKLICH gemeinsam gezeichnet wird (z. B. die fünf Tages-Linien der Messwerte-Welt), nicht die Token-Datei am Stück.
  - **Die FORM kann die Farbstufe mitentscheiden:** `flowGridLine` (`--vp-chart-grid-line` #036672) gilt für „Netz" als LINIE, `flowGrid` (#0ea5a3) für Balken/Flächen und die Rollenfarbe des Energieflusses — Begründung + Zahlen stehen am Feld in `chartTheme.ts`. Wer eine solche Stufe einführt, füttert sie an JEDEM Aufrufer derselben Reihe durch — Kurve, Vergleichs-Overlay UND Legende (`HistoryChart.farbe(t, key, linie)`), sonst bewirbt die Legende einen Ton, den das Canvas nicht zeichnet.
