# AE4 = the money view is a profile-conditional LENS, not a new engine (vp-ae4-money, V1-lite, spec §5 "kein E15").

Ausgelagert aus `frontend/portal/AGENTS.md` am 05.09.2026 (Abschnitt Nr. 2, Punkt 064).

- **AE4 = the money view is a profile-conditional LENS, not a new engine (`vp-ae4-money`, V1-lite, spec §5 "kein E15").** `src/moneyEmphasis.ts` `moneyLayout(emphasisMoney)` is the ONE pure decision (`moneyEmphasis.test.ts`): the AE7 `emphasis.money` level (`prominent`|`secondary`|`minimal`|`hidden`) → `{presentation, showFullMoney, nachweis, hiddenFromHero}`. `AnlageSeite` (`pages/AnlagenPage.tsx`) consults it via `useAdaptiveLive(...).profile` — **only a MIGRATED site (`adaptiveLive.adaptive`) with a profile carries an emphasis; anything else resolves to `prominent` = byte-identical to today** (the AE2/AE3 fallback discipline). Arbitrage (prominent) = the untouched `AnlageHero` + Ertrag + Energie + PeriodTabs/MonthStrip/MonthRail. Peak (`secondary`) = full money kept but framed as Nachweis: a `.vp-money-nachweis-tag` above a muted, smaller hero, and on phone/tablet the live+Fahrplan zones lead (order overrides in the `max-width:1159px` block). Private (`minimal`→hidden) = the big hero is swapped for the quiet `MoneyGlanceCard` ("Erlöse & Wert → im Detail"), and PeriodTabs/MonthStrip/Ertrag/Energie/MonthRail are gated off (`showFullMoney`) — money is de-emphasised, never destroyed (still reachable via the glance card + the existing "Historie & Erlöse" DetailCard). The money math + `AnlageHero`/earnings components are reused UNCHANGED; only where/how-prominent they render varies. CSS: "AE4: profile-conditional money view" block in `index.css`. No new backend, no per-entity attribution (E15/post-v1).
