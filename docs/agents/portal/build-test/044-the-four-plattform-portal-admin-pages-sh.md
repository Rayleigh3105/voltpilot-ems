# The four Plattform (Portal-Admin) pages share ONE console chrome (vp-admin-ux-x8).

Ausgelagert aus `frontend/portal/AGENTS.md` am 05.09.2026 (Abschnitt Nr. 2, Punkt 044).

- **The four Plattform (Portal-Admin) pages share ONE console chrome (`vp-admin-ux-x8`).** Every admin page (`pages/admin/MandantenPage`/`BenutzerPage`/`GeraeteRegistryPage`/`OptimizerPage`) heads with the shared **`AdminPageHead`** (`pages/admin/AdminPageHead.tsx`: IconTile + title + description + optional `actions` slot; category codes the page - Mandanten industry/`building`, Benutzer home/`users`, Registry primary/`list`, Optimizer primary/`settings`) so they read as one operator console, not four bare `h1`s. Placeholder/empty states go through the design-system **`EmptyState`** (`components/States.tsx`), NEVER a bare `<Card><p class="vp-muted">…` - preserve the exact German copy `OptimizerPage.test.tsx` asserts (`Wählen Sie oben einen Mandanten`, `Wählen Sie eine Anlage`, `noch kein Optimizer-Lauf`) when editing the Optimizer states. The top-bar tenant **switcher** (`AppShell` `.vp-context`, admin-only) carries a leading `building` icon + a trailing `chevron-down` caret (native caret hidden) so it reads unmistakably as THE Mandanten control. The Mandanten page leads with a **pulse strip** (`MandantenPulse` + pure `src/adminPulse.ts` `tenantPulse` - Mandanten total + B2C/CI split, derived from the tenants already in hand, NO new API call); a real cross-tenant KPI dashboard is a deferred captain-decided swing (see `docs/admin-ux-assessment.md` + `docs/admin-ux-mockup.html`). Shared admin CSS lives in the "Portal-Admin (Plattform) shared chrome" block in `src/index.css` (`.vp-admin-head`/`.vp-admin-pulse`/`.vp-cell-main`/`.vp-cell-sub`/`.vp-btn-danger`). Tests: `AdminPageHead.test.tsx`, `adminPulse.test.ts`, the admin-switcher render in `shell/AppShell.test.tsx`.
