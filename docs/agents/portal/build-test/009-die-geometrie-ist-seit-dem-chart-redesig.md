# Die GEOMETRIE ist seit dem Chart-Redesign Stufe 1 tokenisiert: src/chartStyle.ts ist das Gegenstück zu chartTheme.ts.

Ausgelagert aus `frontend/portal/AGENTS.md` am 05.09.2026 (Abschnitt Nr. 2, Punkt 009).

- **Die GEOMETRIE ist seit dem Chart-Redesign Stufe 1 tokenisiert: `src/chartStyle.ts` ist das Gegenstück zu `chartTheme.ts`.** Geteilt waren bisher nur die FARBEN; jede Zahl dahinter war Privatsache der Komponente — gemessen NEUN Strichstärken für „Hauptlinie" (1,2–2,5), drei Jetzt-Linien-Stile, vier Balken-Regime, fünf Legenden-Regime. Genau daraus entstand der Eindruck „grob" (Scout `vp-charts-filigran-c7` §4). Wer eine Chart-Fläche anfasst, nimmt `STROKE`/`FILL`/`BAR`/`NOW`/`AXIS`/`FORECAST`/`SMOOTH_SERIES`/`PANELS` VON DORT — eine neue Zahl in einer Komponente ist der Rückfall in den Zustand, den die Datei beendet. Die Regeln heißen F1–F10 (`vp-charts-filigran-c7` §5b) und K1–K11 (`vp-charts-verstaendlich-r2` §3); **wo beide kollidieren, gewinnt die VERSTÄNDLICHKEIT** (r2 §4).
  - **F1 ist eine HIERARCHIE, kein Gleichmaß:** Kernaussage-Serie 2,2 · Kontext 1,7/1,4 · Referenz 1. Gemessen (r2 §2 Befund ①): eine durchgehend dünne Fläche verliert beim Verkleinern überproportional — bei 0,55× Darstellungsmaßstab landet eine 1-px-Linie im Subpixel. Filigranität entsteht aus dem KONTRAST der Stärken.
  - **F5: es gibt EINE Jetzt-Linie** (`nowLineStyle`/`nowLabel`) — 1 px, 3-3 gestrichelt, Ink 55 %. Sie ist eine REFERENZ und trägt deshalb nie eine Serienfarbe (fünf Flächen malten sie im PREIS-Blau). **Auf einer Fläche, die ausschließlich Vergangenheit zeigt, entfällt sie SAMT Vergangenheits-Wash** — der rechte Rand IST dort jetzt (Live-Verlauf).
  - **F6 ist KORRIGIERT: gepunktet heißt PROGNOSE, nicht Zukunft.** Der Börsenpreis für morgen steht fest; ihn zu punkten behauptet eine Unsicherheit, die es nicht gibt. Die Tagesgrenze ist eine Referenz-Haarlinie mit Datum.
  - **⚠ `smooth: true` ist der Faktor 0,5** und erzeugt auf 15-Minuten-Daten Sinus-Überschwinger: eine PV-Kurve schwingt nachts unter Null, ein Ladestand über 100 % — beides BEHAUPTET Messwerte, die nie gemessen wurden. Reihen nehmen `SMOOTH_SERIES` (0,2 + `smoothMonotone`).
