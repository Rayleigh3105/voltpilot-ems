# Meine Anlage v2 = money-centric (captain 2026-07-07, vp-anlage-money-view, modelled on the Deye Copilot app).

Ausgelagert aus `frontend/portal/AGENTS.md` am 05.09.2026 (Abschnitt Nr. 2, Punkt 036).

- **Meine Anlage v2 = money-centric (captain 2026-07-07, `vp-anlage-money-view`, modelled on the Deye Copilot app).** The `AnlageSeite` (`pages/AnlagenPage.tsx`) is now a Deye-style money view: **period tabs `PeriodTabs` (Heute/Monat/Jahr/Gesamt) govern the WHOLE page** via `range` + `at` state (`at` = a strip-tapped month; null = current period; `api.earnings(range, at)`), in month mode the **tappable 12-month `MonthStrip`** (fixed 12-month axis anchored on today, scrolls the selected chip into view), the Gesamtertrag `AnlageHero` (big **Gesamtertrag = Einspeise-Erlös + Wert des Eigenverbrauchs**, "davon +X durch VoltPilots Steuerung" = `savedEur`, up to 4 tiles: Einspeise-Erlös / Wert-des-Eigenverbrauchs-or-kWh-fallback / Ihr Marktwert / Ø Markt Solar), the `ErtragChart` (ECharts bars, best bucket green) + `bestBucketText`, the energy stats row (`EnergyStatsRow`), a compact `EnergyFlow` "Jetzt" block, and "Mehr" cards (Fahrplan/Historie/Wetter). **Technik moved BEHIND the gear icon** (`vp-gear-btn` in the header → the new `technik` subpage `#/anlage/{id}/technik` rendering `TechnikSection`; the retired `#/standorte|geraete` hashes now redirect to it) - but WARNINGS (device-offline amber `composeSiteSentence`, `batteryWithoutDevice` alert) stay prominent at the TOP. Render pieces in `components/MoneyView.tsx` + `components/ErtragChart.tsx`; ALL derivation is the pure, unit-tested **`src/anlage.ts`** (`energyLabel` kWh↔MWh, `periodLabel`, `stripSlots`/`stripValueLabel`, `bucketAxisLabel`/`bucketTooltipLabel`, `bestBucket`/`bestBucketText`, `ertragTitle` - `anlage.test.ts`). CSS "Money-centric Meine Anlage v2" block in `src/index.css`. **Honest euros + dynamic tariff (task `vp-anlage-nachvollziehbar`, 2026-07-08):** the Wert-des-Eigenverbrauchs tile shows a euro value per the site's `tarifArt` (`dynamisch`/`fest`/`ohne` + `tarifParamCtKwh` - REPLACES the old `strompreisCtKwh`): `dynamisch` values each self-consumed kWh at its 15-min Börsenpreis + the optional Aufschlag (computed slot-by-slot in the backend SQL -> `eigenverbrauchsWertEur`), `fest` at the fixed price, `ohne` shows kWh only (`eigenverbrauchsWertEur=null`, `gesamtertragEur` = feed-in revenue alone). The tariff is edited via the shared `components/TariffFields.tsx` on the **Technik gear subpage ONLY** (`SiteEditForm`/`CreateSiteDrawer`/onboarding `AnlageFlow` Feineinstellungen), never on the money view. **Nachvollziehbarkeit:** every euro figure in `AnlageHero` carries an `InfoTip` (portals to body, viewport-clamped) whose ONE plain-German sentence is a pure builder in `src/anlage.ts` (`einspeiseProvenance`/`eigenverbrauchProvenance`/`gesamtertragProvenance`/`savedProvenance`) - real quantities × prices with the effective average derived from `eigenverbrauchsWertEur/selbstverbrauchKwh`; the `ErtragChart` gained a "Was zeigt das?" `ChartSubtitle` + the best-bucket as a `ChartInsight`; `EnergyStatsRow` renamed to "Eingespeist / Selbst genutzt / Über Batterie" with a per-tile hint (`energyTiles()`). The DV benchmark tiles (Ihr Marktwert / Ø Markt Solar) come from PR-93's `realizedExportCtKwh`/`marketValueSolarCtKwh` (`fleet.ts marktwertBenchmark` feeds the "Ihr Marktwert" InfoTip).
