# Forward "Erwarteter Marktwert Solar" on the money hero (captain 2026-07-09, vp-expected-marktwert-solar).

Ausgelagert aus `frontend/portal/AGENTS.md` am 05.09.2026 (Abschnitt Nr. 2, Punkt 037).

- **Forward "Erwarteter Marktwert Solar" on the money hero (captain 2026-07-09, `vp-expected-marktwert-solar`).** One calm line under the `AnlageHero` tiles - "Erwarteter Marktwert Solar (nächste N h): X,X ct/kWh" + an `InfoTip` stating the plain formula ("Day-Ahead-Preise gewichtet mit Ihrer PV-Prognose"). It is the FORWARD companion to the realized DV benchmark (`marktwertBenchmark`), rendered for ANY site (not DV-only) whenever the backend returns a value. Derivation is the pure, unit-tested `src/anlage.ts` `expectedMarketValueLine(money)` (formats ct/kWh via `ctAmount`; horizon = the covered forward window `[from, to]` + the last slot's 15 min, rounded to whole hours, `>=1`; falls back to "kommende Stunden" without bounds) → null when `expectedMarketValueSolarCtKwh == null`, and the component then renders NOTHING (honest, never a fake 0). Fields on `EarningsSite` (`api.ts`): `expectedMarketValueSolarCtKwh`/`...From`/`...To`/`...Slots`. CSS `.vp-money-forward` in `index.css`. Backend computes it in `EarningsRepository.expectedMarketValue` (see the root AGENTS.md realized-earnings section). `anlage.test.ts` pins the wording (incl. the negative-value case + the null-hides case).
