# Auf „Edge-Updates" ist die Flotten-Matrix ENTFALLEN (E2).

Ausgelagert aus `frontend/portal/AGENTS.md` am 05.09.2026 (Abschnitt Nr. 2, Punkt 076).

- **Auf „Edge-Updates" ist die Flotten-Matrix ENTFALLEN (E2).** Sie war die strukturelle Ursache der „zwei Wahrheiten auf einer Seite"; ihre drei Aufgaben wohnen jetzt im Puls, in der Geräte-Zeile einer Aktualisierung und auf der Geräte-Seite. Übrig bleibt ein RUHIGER Verweis (`vp-muted`, kein zweiter blauer Kasten neben der Ruhezustands-Zeile) samt der Crossover-Zeile. Die Geräte-Zeile ist der Weg ins Gerät — ein ENTFERNTES Gerät ist bewusst nicht klickbar, ein Klick führte ins Leere.
