# Adaptive live view (AE2 energy flow + AE3 tiles/module strip) is topology-driven, with a byte-identical v1 fallback.

Ausgelagert aus `frontend/portal/AGENTS.md` am 05.09.2026 (Abschnitt Nr. 2, Punkt 063).

- **Adaptive live view (AE2 energy flow + AE3 tiles/module strip) is topology-driven, with a byte-identical v1 fallback.** `useAdaptiveLive(siteId)` (`src/useAdaptiveLive.ts`) fetches `api.topology` + `api.usageProfile` with a silent LIVE-cadence poll, fail-soft: any error or a site with NO v2 entities (`adaptive===false`) leaves the host on the existing v1 telemetry view - so un-migrated sites are untouched. When a topology is present, the merged home's Komponenten-Board derives per-component rows (`livePuls.componentRows`) and the energy flow swaps to `AdaptiveEnergyFlow`. ALL derivation is pure + unit-tested: `src/adaptiveFlow.ts` `layoutFlow` (AE2 geometry - N role-grouped circle nodes, producers top / storage left / consumers right / grid bottom; viewBox GROWS with member counts; direction from the topology node's `direction`, `'in'`→node→hub `vp-flow-on`, `'out'`→hub→node `vp-flow-rev`), `src/adaptiveLive.ts` (AE3 `deriveTiles` - one aggregate tile per PV/Speicher/Netz role + one per consumer entity with read-only device switches; `liveState`; `hasTopology` = the fallback gate; `composeAdaptiveSentence`/`profileChip` retired with the Cockpit+Live merge — no consumer remained), `src/flowModules.ts` (AE3 §4 "Was läuft" strip reflecting the AE7 `signals.activeStrategyNodeTypes` + governance - gated market/peak/atypical-grid show a lock, the mockup's per-profile offer rule is `offeredWhenInactive`), `src/adaptive.ts` (role palette + entity-type icons + `CONTROLLABLE_CONSUMER_TYPES` + read-only `controlPreset`). Device control switches are DISPLAY-ONLY in v1 (E3b wires real control). The renderer (`components/AdaptiveEnergyFlow.tsx` faithful to `ae0-mockups.html` renderHub - lightning hub + soft circle nodes + animated dashed spokes) is thin. Emphasis: the view reads `profile.emphasis` (AE7) - the money hero stays on the Anlagen-Seite (AE4 owns money-conditional wiring). CSS block "Adaptive live view" at the end of `index.css`. Verified in-browser 1440/768/narrow, zero horizontal overflow (the flow SVG scales to its container via `preserveAspectRatio` + `max-width:100%`).
