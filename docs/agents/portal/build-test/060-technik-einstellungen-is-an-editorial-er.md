# "Technik & Einstellungen" is an editorial, erklärbar page (task vp-technik-erklaerbar).

Ausgelagert aus `frontend/portal/AGENTS.md` am 05.09.2026 (Abschnitt Nr. 2, Punkt 060).

- **"Technik & Einstellungen" is an editorial, erklärbar page (task `vp-technik-erklaerbar`).** `pages/AnlageTechnik.tsx` `TechnikSection` renders `<div class="vp-technik">` = a slim sticky left jump-nav (`.vp-technik-nav`, desktop only, hidden `<=980px`, IntersectionObserver scroll-spy in `useScrollSpy`, guarded for jsdom) + six explained `TechCard` sections in the captain order: **Meine Anlage / Mein Gerät / Mein Speicher / Vergütung & Tarif / Registrierung / Anlage löschen** (icons `home`/`cpu`/`battery`/`euro`/`file-text`/`trash` - the first three added to the design-system `Icon` set, NO emojis). Four principles: group by meaning, **read-first** (plain rows first, form only on "Bearbeiten"), **collapse jargon behind a "Technische Details" disclosure** (`TechnischeDetails`: max charge/discharge, Wirkungsgrad, steuerndes Gerät, device-ID/ref, MaStR internals), and one explaining sentence per section + an `InfoTip` per Fachbegriff (anzulegender Wert, Netzladen, Wirkungsgrad, Stromtarif). Desktop = airy borderless blocks (hairline header + whitespace); **phone (`<=720px`, `useIsPhone` matchMedia, guarded) = bordered COLLAPSIBLE cards** (calm summary line when closed, chevron toggles; the `TechCard` header is a `<button>` on phone and a `<div>` with a pencil `action` on desktop). CSS block "Technik & Einstellungen (erklärbar)" in `index.css` (`.vp-technik*`/`.vp-tech-*`/`.vp-kv*`); verified in-browser 1440/768/375, zero horizontal overflow, on a throwaway Vite harness (deleted).
  - **The single site-edit form was SPLIT into two focused inline forms** - `StammdatenEditForm` (name/Gebotszone/Anlagentyp + interactive `LocationMap`) and `VerguetungEditForm` (anzulegender Wert DV-only + `TariffFields` + Netzladen switch, keeps the Ausschließlichkeitsprinzip warning). **Both still POST the FULL site representation** via the `buildSitePayload(site, overrides)` helper, because the backend `UpdateSiteRequest` is a full-representation record (name `@NotBlank`, `plantKind`/`tarifArt`/`biddingZone` DEFAULT when omitted) - a partial body would blank the untouched group. So each form edits only its slice but carries the other group's current values through unchanged. The old `SiteEditForm` export is gone; `AnlageTechnik.test.tsx` targets `VerguetungEditForm` for the netzladen tests.
  - **The battery-without-device warning is a real failure, so it renders at the card's ALWAYS-VISIBLE slot** (`TechCard alwaysVisible`, shown even on a collapsed phone card + an amber "Speicher ohne Gerät" summary), NOT in the collapsible body. `BatteryControlSection` gained `hideWarning` (the card passes it `true` and owns the warning; default false keeps the standalone/unit-tested render). The battery read-first shows only Kapazität; the installer params + "Speicher bearbeiten" live behind its own "Technische Details".
  - **`LocationMap` gained a `readonly` prop** (default false) for the Meine-Anlage read-first map preview: no click-to-place, non-draggable pin, no coord expander/Entfernen - a display-only map. The three site forms keep the full interactive editor.
