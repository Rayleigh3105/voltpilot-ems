- **M0 Modus-Mengen-Read-Model — `src/surface.ts` is the contract M1–M4 render from (Epic "Projektion" #527, ticket #528; design `data/vp-anlagen-face-k9/report.md` §1/§3/§7 + `feedback.md`).** The Anlagen-Seite becomes a PROJECTION: `surface = base(entities) ∪ ⋃ module(m)`. It **supersedes the AE7 single face**: `usageProfile.ts` collects the very same signals and then collapses them via argmax (`deriveDefault`) into one `emphasisFor()` raster — `surface.ts` keeps the signals and **drops the reduction**, deriving the SET of active modes. Pure, deterministic, no React/network (the `adaptiveLive.ts`/`moneyEmphasis.ts` consumer precedent); composed client-side from shipped endpoints only (AE7 `signals`, the flows list, `SiteDto` money/optimizer echo, the v2 entities) — **no server twin, no new endpoint** (`GET /sites/{id}/surface` is explicitly optional later hygiene). Exports: `activeModes(site)`, `baseSurface(entities)`, `anlageSurface(site)` (base + modes + `cockpitBlocks` + `moneyStreams` + `deepViews`), plus `telemetryChannels`/`moneyStreams`/`cockpitBlocks`/`deepViews`/`hasMode`. Vectors for all five Ausprägungen (Privat/Gewerbe/Markt/Multi/leer) incl. their **negative proofs** live in `surface.test.ts`.
  - **Activation (report §1.2, amended by vp-nacht-bezug-e7 §3.3):** **Eigenverbrauch is NO LONGER a mode** — it is base behaviour, so `surface.ts` `activeModes` never emits it and there is no `eigenverbrauch` ModeKind; its Kennzahlen (`eigenverbrauchsWertEur`, Autarkie/Quote) ride the Marktvermarktungs-Manifest + MoneyView/Cockpit-rings/Historie, not a mode card. Marktvermarktung = `plant_kind=direktvermarktung` ∨ `vp.strategy.market` ∨ (`netzladen_erlaubt` ∧ dynamischer Tarif — **F4 decided: yes**); Lastspitzenkappung = `leistungspreis_eur_kw` ∨ `vp.strategy.peakshaving`; Atypische Netznutzung = `vp.strategy.atypical-grid` (card-only/preview, E5b economics not built); Automation = **one mode per active flow without a strategy node** (`flows/steuerung.ts flowMode`). The `vp.strategy.selfconsumption` node + the `eigenverbrauch` shelf profile + the `private` usage-profile OVERRIDE were removed (`private` stays the DERIVED household emphasis only).
  - **Honesty rules baked into the manifests:** `origin: 'masterdata' | 'flow'` — a master-data-only mode renders "Von VoltPilot eingerichtet" and `action: 'none'`, and `action: 'open-flow'` requires a RESOLVED `flowRef` (never promise an editable flow that does not exist). Automation money streams are `unattributed: true` → the row shows "—" (per-rule attribution is E15, not built). Peak money carries `period: 'billing-period'`, EV/market `'range'` — the stack must label the period, never blind-sum.
