- **"Meine Anlage" v4 = a real DESKTOP 3-zone dashboard + a money-first PHONE scroll (captain 2026-07-08, `vp-anlage-seite-v4`).** `pages/AnlagenPage.tsx` `AnlageSeite` renders `<div class="vp-anlage-dash">` with three zone wrappers (`vp-zone-money` / `-live` / `-rail`) plus a full-width `vp-dash-fahrplan` band and `vp-dash-deep` cards. **The responsive trick (index.css "Meine Anlage v4"):** at `>=1160px` the dash is a `grid-template-columns: 5fr 4fr 3fr`, each zone a gap-free flex column (Zone A = hero+Ertrag+Energie, Zone B = live flow+Steuerung+Plan-traf-zu, Zone C = vertical `MonthRail`+`HealthChecklist`), fahrplan/deep span `1 / -1`; below 1160 the zones become `display: contents` so their inner `vp-dash-*` blocks reflow money-first via the `order` property (hero → plantraf → live → fahrplan → control → ertrag → energy → deep; rail+health hidden, horizontal `MonthStrip` shown). **Every `vp-dash-*` wrapper needs `min-width: 0`** or one wide child (a chart, a big number) blows out the `1fr` track and overflows the viewport (the exact 375px overflow bug found + fixed in-browser). Verified 1440/768/375, zero horizontal overflow. The money hero (`AnlageHero`), tarif provenance InfoTips, honest-euro gate and DV benchmark from v2/v3 (PR 94/103) are untouched - v4 only re-lays-out and adds four data-grounded widgets.
