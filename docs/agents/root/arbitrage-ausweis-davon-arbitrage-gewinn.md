# Arbitrage-Ausweis ("davon Arbitrage-Gewinn" in the earnings hero)

Ausgelagert aus `AGENTS.md` am 05.09.2026 (Abschnitt Nr. 68).


Captain pick 2026-07-07 (review-session decision 5, task vp-arbitrage-ausweis): a grid-charging site's earnings hero shows what the netzladen permission concretely earned.
No schema change - a read-side attribution over the existing rollups.

- **The honest split (storage-mix model, `EarningsRepository.arbitrageSplit`):** a deterministic one-pass walk over a netzladen site's covered 15-min slots in time order, carrying the battery content as two pools (pv-charged vs grid-charged kWh; grid share of a slot's charge = `max(0, charge - max(pv - load, 0))`, charge applied before discharge, discharge draws proportionally from the mix). `arbitrageEur` = grid-attributed discharge revenue minus grid-charge purchase cost; `pvShiftEur` is computed as the REMAINDER `saved - arbitrage`, so the reconciliation `arbitrage + pvShift == saved` holds EXACTLY by construction. Documented assumptions (method Javadoc): pre-window battery content counts as solar (conservative - never inflates arbitrage), round-trip losses debit both pools proportionally, sub-slot interleaving is invisible (slot granularity, same as the saved total), the Marktprämie delta stays entirely on the PV side (grid-charged energy is never premium-eligible), and the flag is read at query time (no historical mode tracking).
- **Null, never a fake zero:** both fields are null for `netzladen_erlaubt = false` sites AND for windows without grid-charged energy (the repo only returns sites with `gridChargedKwh > 0`). Fleet totals: `arbitrageEur` sums the split sites; `pvShiftEur = savedEur - arbitrageEur` over the WHOLE fleet (no-split sites cannot grid-charge, so their entire saved is PV-shift) - fleet-level reconciliation holds too. On `EarningsSiteDto`/`EarningsTotalsDto` + `openapi.yaml`.
- **Portal:** one calm extra line under the hero proof ("davon durch Netzladen verdient: +X €"; a losing period says "Netzladen hat in diesem Zeitraum X € gekostet" - sign-honest, wording in `fleet.ts arbitrageLine`), and the fine print gains the one-sentence attribution ("Der Netzladen-Anteil ist der Verkaufserlös der aus dem Netz geladenen Energie abzüglich ihrer Einkaufskosten.") only while the line shows. Renders for fleet totals AND the site-scoped hero (`HeroMoney.arbitrageEur`); per-site card teaser unchanged. CSS `.vp-fleet-hero-arb`.
- **Demo-data caveat:** the dev seed's Dachau charges 40 kW against a ~67 kW midday PV surplus, so it never grid-charges and the demo hero shows NO arbitrage line (the line needs real grid-charge slots; seed them manually when demoing).
- **Tests:** `PortalApiTest.earningsSplitArbitrageFromPvShiftForGridChargingSites` (hand-computed multi-slot day: pre-window discharge -> solar, cheap-night grid charge, noon PV charge, evening 50/50 mix draw; exact reconciliation per site + fleet; EEG twin with identical measurements gets NO split; solar-only merchant gets NO split; RLS); portal `fleet.test.ts` (`arbitrageLine` wording incl. negative + negative-zero, fine-print sentence gating).
