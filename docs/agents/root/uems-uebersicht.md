# UEMS — Unternehmens-Energiemanagement: Wegweiser

Diese Seite sammelt die Wegweiser-Einträge aller Bau-Pakete des Programms Unternehmens-Energiemanagement (UEMS), damit der Themen-Index von `AGENTS.md` nur EINE Zeile dafür trägt. Die Begriffe stehen im Glossar [`docs/fachmodell/README.md`](../../fachmodell/README.md), die bindenden Schnittstellen in [`docs/contracts/v2/README.md`](../../contracts/v2/README.md).

Die Dateinamen am Zeilenende sind relativ zu diesem Ordner (`docs/agents/root/`). **Nicht ganze Dateien in den Kontext lesen — greppen.**

## Verträge

- **UEMS-Zustandsvokabular „liefert Daten“ / „steuert“ als Vertrag mit Vektoren** — Toleranz `min(max(3 × Kadenz, 300 s), 86 400 s)`, Lücke ab 2 × Kadenz, GENAU EIN „steuert nicht“-Grund in fester Reihenfolge; Zwillinge Java `uems/ZustandAbleitung` ⟷ TS `uemsZustand.ts` gegen `docs/contracts/v2/uems-zustand-vectors.json` — noch ruft niemand an · `uems-zustandsvokabular-liefert-daten-st.md`
- **UEMS-Funktions-Zustand je Standort und Teilnahme je Anlage als Vertrag mit Vektoren** — Rang `kein_objekt < archiviert < entwurf < eingerichtet < angehalten < aktiv`, Standort = höchster Zustand seiner Teilnahmen; Prüfliste vor Start UND Fortsetzen nennt, was fehlt; `steuert` bekommt den ZUSTAND, nie den rohen Ruhe-Eintrag; Zwillinge Java `uems/FunktionZustandAbleitung` ⟷ TS `uemsFunktion.ts` gegen `docs/contracts/v2/funktion-zustand-vectors.json` — noch ruft niemand an · `uems-funktions-zustand-je-standort-und-t.md`
- **UEMS-Herkunftsvertrag je Messwert als Vertrag mit Vektoren** — 15 Angaben je Wert, Ableitung Zeit (E13) → Sequenz → Herkunft vollständig → Rolle zur MESSZEIT (E4) → Idempotenz Reihe + Messzeit JE SPUR (E3) → Zustellart; Java `uems/MesswertHerkunft` gegen `docs/contracts/v2/messwert-herkunft-vectors.json`, jeder Fall gegen das Referenzunternehmen geprüft — noch ruft niemand an · `uems-herkunftsvertrag-je-messwert-als-v.md`
- **UEMS-Ortsbaum: zeitgültige Zuordnungen als Vertrag mit Vektoren** — „gültig ab“ = Tag 00:00 am Standort, `bis` = LETZTER Tag (DB: `daterange(ab, bis, '[]')`), neues „gültig ab“ beendet das laufende am Vortag, Standort einer Messstelle = Wurzel ihres Ortes an dem Tag; Zwillinge Java `uems/OrtsbaumAbleitung` ⟷ TS `uemsOrtsbaum.ts` gegen `docs/contracts/v2/ortsbaum-vectors.json` — noch ruft niemand an · `uems-ortsbaum-zeitgueltige-zuordnungen-a.md`
- **UEMS-Messstellen-Vertrag: Kennzeichen, Größen, Quellenbindung und Stellung als Vertrag mit Vektoren** — Kennzeichen `MS-0001` nie an eine andere Messstelle weitergegeben (auch früher/archiviert belegt), Quellenbindung in fester Prüfreihenfolge (neue Quelle beendet die laufende genau zu ihrem Beginn, Lücken sichtbar), je Anlage und Richtung ein Hauptzähler am selben Zähler; Zwillinge Java `uems/MessstelleRegeln` ⟷ TS `uemsMessstelle.ts` gegen `docs/contracts/v2/messstelle-vectors.json` — noch ruft niemand an · `uems-messstellen-vertrag-kennzeichen-gro.md`
- **UEMS-Datenquelle und Zuständigkeit als Vertrag mit Vektoren** — Zeiträume halboffen auf die Minute, nie überlappend/rückwirkend, beendet statt überschrieben; Eindeutigkeit je Box, Doppel-Lesen nur als bestätigte Vergleichsquelle (E10 = B), Prüfung von GENAU der Ziel-Box; Fehlerklassen = Verbindungstest-Wörter; Fähigkeiten-Tabelle `edge-capabilities.json` (`supports[]` übersteuert); Zwillinge Java `uems/DatenquelleRegeln` ⟷ TS `uemsDatenquelle.ts` gegen `docs/contracts/v2/data-source-vectors.json` — noch ruft niemand an · `uems-datenquelle-und-zustaendigkeit-als.md`
- **UEMS-Rechte-Matrix als Daten und Rechte-Vertrag mit Vektoren** — 48 Aktionen × 7 Rollen mit Kennung je Zeile (`docs/contracts/v2/rechte-matrix.json`, die `.md` wird ERZEUGT, `tools/rechte_matrix.py --check`); `darf` prüft Geltungsbereich vor Aktion (404 → 403 + `rolle_noetig`), Anlage über ihren Standort zum Stichtag, Teilansicht ab zwei Standorten, OCPP-Stufe aus der Zuweisung (E13); Zwillinge Java `uems/RechteAbleitung` ⟷ TS `rechte.ts` gegen `rechte-vectors.json` — noch ruft niemand an · `uems-rechte-matrix-als-daten-und-rechte-v.md`
- **UEMS-Rechte-Matrix: Nachträge aus AP-04 §6.7, AP-05 §6, AP-06 §4.8, AP-07 §4.10 und geprüfte Routen-Kennungen** — Zeile ohne `nachtrag` = Konzept-Tabelle AP-03 §4.3 (byte-gleich, `konzept_tabelle.sha256`), Zeile mit `nachtrag` = Rechte-Abschnitt des späteren Pakets (`herkunft` beginnt damit, `wie` = Zellen von X); `nachtraege` ordnet JEDE Handlung einer Kennung zu; neu `messstelle.ansehen`, `ereignisse.ansehen`, `datenquelle.bearbeiten`/`.zustaendigkeit`/`.ansehen`, umbenannt `messstelle.quelle`; W-R8 … W-R11 (⚠ W-R9: Zuständigkeit ohne Energiemanager); `RechteKennungenDerRoutenTest` hält jede Kennung der UEMS-Routen-Kommentare an die Matrix · `uems-rechte-matrix-nachtraege.md`
- **UEMS-Ereignis-Vertrag Box → Cloud und das geschlossene Ereignis-Vokabular** — 23 Arten mit Urheber (`box`·`datenannahme`·`writer`·`cloud`·`kunde`), Bezug, Zeitform (halboffen/geschlossen, offen nur `data_gap`/`handover`, nie von der Box) und Kundensatz; Umschlag `…/v2/events` 2.1 (Einheit, ohne `box`) + `events.raw` 1.0; append-only per Fortschreibung; Java `uems/EreignisVokabular` prüft, TS `uemsEreignis.ts` spricht, `services/ingest` `EventsContractSchemaTest` — noch ruft niemand an · `uems-ereignis-vertrag-box-cloud-und-das.md`
- **UEMS: `measurement-samples` 2.1 — optionale Herkunftsfelder, 2.0 bleibt gültig** — `applied_revision` je Umschlag + `entity_id` je Sample NUR unter 2.1 (eigene Schema-Datei, 2.0 byte-gleich, fremde Felder weiter abgewiesen); Ingest nimmt beide an und entfernt `entity_id` vor `measurements.raw` (Writer streng, Durchreichen = IP-5); Box-Core `parseBatch` ist streng → IP-18 braucht Core + Palette zusammen · `uems-measurement-samples-2-1-herkunftsfelder.md`
- **UEMS-Führende Box: `LeadDeviceService` ersetzt die Einzel-Gateway-Weiche in Registry-Push und Flow-Aktivierung** — EINE Ableitung (`uems/FuehrendeBoxAbleitung`, Vorrang aus `DatenquelleRegeln.fuehrung`): `site.lead_device_id` nur, wenn die Box in DIESER Anlage angemeldet ist (sonst `gespeichert_nicht_in_anlage`, nie ausweichen), sonst Speicher-Box, sonst einzige Box, sonst `keine_wahl`/`keine_box`; für den Bestand (lead NULL) verhaltensgleich zur alten Weiche, `gatewayAmbiguous` = nur `keine_wahl`; Vektoren `lead-device-vectors.json` · `uems-fuehrende-box-lead-device-service.md`

## Tabellen

- **UEMS-Ortsstruktur-Tabellen: Unternehmen, Standort, Anlagen-Zuordnung, Änderungsprotokoll** — `V20260911100000`: Backfill NUR je Mandant ein `unternehmen`; alle FKs `ON DELETE RESTRICT`, darum räumt `TenantRepository.offboard` sie ausdrücklich ab; `tenant_id` vorn in jedem Exklusions-/Unique-Schlüssel (prüft vor dem FK, ohne RLS); CHECK nimmt NULL an → `coalesce(…, false)` · `uems-ortsstruktur-tabellen-unternehmen-st.md`
- **UEMS-Messstellen-Tabellen: Messstelle, Nebengröße, Kennzeichen-Belegung, Zähler, Änderungsprotokoll** — `V20260911140000`: jedes je getragene Kennzeichen steht per Trigger in `messstelle_kennzeichen` (nie weitergegeben, auch früher/archiviert); automatische Vergabe `MS-0001` nur in EINER Transaktion unter Zeilensperre; gespeichert nur die Zustands-Eingänge, nie die Stufe; Postgres prüft CHECKs in Namensreihenfolge · `uems-messstellen-tabellen-messstelle-ne.md`
- **UEMS-Orte-Tabellen: Gebäude, Bereich, Ort-Zuordnung, Bezugsfläche** — `V20260911110000`: `ort` (Gebäude UND Bereich), woran er hängt nur je Tag in `ort_zuordnung`; die Art-Regel als zwei FKs über berechnete Art-Spalten (nie Bereich unter Bereich); Fläche = ganze m² > 0, „nicht erhoben“ ist keine Zeile; „Ziel besteht“/Name je Eltern prüft der Schreibweg · `uems-orte-tabellen-gebaeude-bereich-ort.md`
- **UEMS-Datenquellen-Tabellen: Datenquelle, zeitgültige Zuständigkeit je Box, führende Box** — `V20260911150000`: Zeiträume HALBOFFEN auf die Minute (`tstzrange … '[)'`, nicht Tage), Exklusion je Quelle und je Box+Weg (Kopie von Protokoll/Adresse per FK `ON UPDATE CASCADE`); `device_id` ohne FK (Trigger prüft beim Eintragen, Unclaim bricht nicht), `site.lead_device_id` `SET NULL (spalte)`; Offboarding löst `measurement_point.data_source_id` zuerst · `uems-datenquellen-tabellen-datenquelle-z.md`
- **UEMS-Geräte-Tabellen: Einbau, Karten, Speisung der Komponenten — und die Lese-API** — `V20260911200000`: EINE Zeile `geraet` = EIN Einbau (`kennzeichen` GR-4 bleibt, `einbau_kennzeichen` Z-5a/Z-5b wechselt, Vorgänger = gleiches Kennzeichen), Speisung zeitgültig in `geraet_komponente` statt Spalte an `measurement_point`, Karten in `geraet_teil` nur am Controller; Ableitung je Bestands-Komponente genau ein Gerät (Hybrid trägt seine komponierten Geschwister ohne eigene Verbindung, Seriennummer NUR aus `kaco_http` — Deye-`serial` ist der Logger), `→ site` CASCADE; `GET /api/v1/sites/{id}/geraete`, `GET /api/v1/geraete/{id}`; neue Komponenten bekommen ihr Gerät im Anlege-Weg nach derselben Regel (`V20260911240000`: Constraint-Trigger zur Commit-Zeit → `uems_geraet_ableiten_fuer`), das Messkanal-Read-Model zeigt es als `geraet` · `uems-geraete-tabellen-einbau-karten-spei.md`
- **UEMS-Ereignis-Tabelle `messreihe_ereignis`: append-only, nie gelöscht — Bestands-Spiegel und `events.raw`** — `V20260911260000`: keine Retention/Kompression, kein FK auf Löschbares (nur Offboarding räumt, `tenant` RESTRICT), App nur SELECT+INSERT, UPDATE-Trigger; eine Zeile je Meldung (Fortschreibung = weitere Zeile, gleiche `ereignis_id`), Idempotenz über den Fingerabdruck `meldung`; Bezug wörtlich in `kennungen` + eindeutig aufgelöste `*_id`; Vokabular in `messreihe_ereignis_vokabular()` (CHECKs); Writer spiegelt jedes neue `device_measurement_event` in derselben Transaktion (`aus_bestand`) und hängt `events.raw` an (`EventsRawConsumer` + Writer-Zwilling `EreignisVokabular`) · `uems-messreihe-ereignis-tabelle.md`

## Schnittstellen

- **UEMS-Messstellen-API: anlegen, lesen, bearbeiten, anhalten, fortsetzen, archivieren** — `/api/v1/messstellen` in snake_case (die Antwort IST die Messstelle des Schemas + `id`/`fehlt`/`angehalten_ab`/`archiviert_am`), Anfrage streng (unbekanntes Feld 400), Regeln nur aus `MessstelleRegeln`, Urheber an EINER Stelle (`ProtokollAkteur`), Übergänge auf die Minute, nie Zukunft, streng nach dem Vorgänger · `uems-messstellen-api-anlegen-lesen-bear.md`
- **UEMS-Messstelle zuordnen: Ort und elektrische Stellung, zeitgültig je Tag** — `V20260911230000` `messstelle_ort`/`messstelle_stellung`, `PUT /api/v1/messstellen/{id}/ort|stellung` (Tag, Vortag beendet, `korrektur`, rückwirkend im Protokoll), `GET …/{id}/standort?am=`; Ort über `OrtsbaumAbleitung.eintrag` am Baum von `StandortService`, Stellung über `MessstelleRegeln.stellungPruefen` an jedem Änderungstag inkl. der Unterzähler; bis IP-13 ist jeder zweite Hauptzähler 409; Haken `OrtsbaumMessstellen` gefüllt (Archiv-Sperre, `messstellenZahl`); Prozess/Kostenstelle offen · `uems-messstelle-ort-stellung-zuordnung.md`
- **UEMS-Standort-Lesemodell: Unternehmen und Standorte zum Stichtag** — `GET /api/v1/unternehmen`, `GET /api/v1/standorte?stichtag=` (+ `/{id}`), additiv `standort {id, name, kurzzeichen, gueltigAb}` an `/overview` und am NEUEN `/sites/{id}`; Ableitung = `OrtsbaumAbleitung.standAm`, ein Standort besteht ab `created_at` ODER früher, wenn etwas früher an ihm hängt; ohne Unternehmen-Zeile `nicht_angelegt`, nie 500; neuer Mandant bekommt sein Unternehmen im selben Statement (`TenantRepository.create`) · `uems-standort-lesemodell-unternehmen-st.md`
- **UEMS-Datenquellen-API: anlegen, bearbeiten, von genau der Box prüfen, zuweisen, Protokoll** — `/api/v1/sites/{siteId}/data-sources` in snake_case, Urteil nur aus `DatenquelleRegeln` (erste Box = `anlegen`, weitere = `wechsel`), Prüfergebnis nie aus der Anfrage sondern aus `data_source_aenderung` (jüngste Prüfung von GENAU der Box für die heutige Adresse), `ProbeService.probeBox` fragt auf dem Topic der Box (Heimat-Anlage), Wechsel = beenden + eintragen in EINER Transaktion · `uems-datenquellen-api-anlegen-bearbeiten.md`
- **UEMS-Messkanal-Read-Model und Größe/Richtung je Messpunkt (Katalog 2026.09.11.1)** — `GET /api/v1/sites/{siteId}/komponenten/{entityId}/messkanaele` liefert je Selektion Kanal, Anzeigename, Einheit, Wertart, Vertrags-Größe/-Richtung (Eingänge der Passung) + Katalogwörter `quantity`/`direction`; der Katalog trennt Inhaltsstand (`VERSION`) und Laufzeitstand der Box (`RUNTIME_VERSION`, `MeasurementCatalog.version()`), Box-Ableitungen bleiben byte-gleich · `uems-messkanal-read-model-richtung-groesse.md`
- **UEMS-Standort-Schreibrouten: anlegen, bearbeiten, archivieren, wiederherstellen + `PUT /api/v1/unternehmen`** — Regeln NUR aus `OrtsbaumAbleitung` (Baum des Lesemodells, auf Kurzzeichen umgeschlüsselt); `V20260911210000`: EINE Kurzzeichen-Belegung für Standort UND Gebäude/Bereich (nie wiederverwendet) + Zähler `uems_ort_kurzzeichen`; je Schreibvorgang genau ein `ort_aenderung`-Eintrag über `OrtProtokoll`; die Archiv-Lücke lebt nur im Protokoll-Paar archiviert → wiederhergestellt; Messstellen-Sperre über den Haken `OrtsbaumMessstellen` (AP-04 IP-7) · `uems-standort-schreibrouten-kurzzeichen-archiv.md`
- **UEMS-Gebäude/Bereich-Schreibrouten und Ortsbaum je Standort** — `GET /api/v1/standorte/{id}/orte?stichtag=`, `POST …/orte`, `PUT /api/v1/orte/{id}`, `PUT /api/v1/orte/{id}/flaeche`; jede Regel aus `OrtsbaumAbleitung` gegen den Baum des Lesemodells (Anlegen = `eintrag` mit dem neuen Knoten ohne Intervall → 400/422/409 mit Vertragsgrund; Name = `nameBelegt` am ersten Tag UND heute; Fläche = NEU `flaecheEintrag`, gleicher Tag = Korrektur); Zeitzone des STANDORTS für „gültig ab“ und „rückwirkend“; dieselben Bausteine wie IP-4 (`OrtFelder`, `OrtKurzzeichen`, `OrtProtokoll`, `OrtAnfrage` — ganze Zahlen streng), Schreibvorgänge je Kundenbereich nacheinander (Sperre auf `unternehmen`); `messstellenZahl` = `null` bis AP-04 IP-7 · `uems-orte-schreibweg-gebaeude-bereich-fl.md`

## Fachmodell

- **UEMS-Fachmodell: das EINE Glossar für alle Pakete des Unternehmens-Energiemanagements** — Standort · Anlage · Netzanschluss · Messstelle · Messkanal · Datenquelle mit Kardinalität, Zeitgültigkeit und Zustandsvokabular; `docs/fachmodell/` ist die Referenz, die Auswirkungs-Karte sagt je heutiger Tabelle, was aus ihr wird · `uems-fachmodell-das-eine-glossar-fuer-al.md`
- **UEMS-Referenzunternehmen Ahrenberg: die EINE Beispielquelle aller Pakete** — Kennzeichen, Werte und Zeitpunkte nur aus `docs/contracts/v2/uems-referenzunternehmen.json`; tagesgenau = Tag + LETZTER Tag, minutengenau = halboffen, `U` = Unternehmen als Ort, rückwirkend mit `eingetragen_am` + Ortsbaum-Abzeichen, Enddatum einer Unterstützung einschließlich; die Zwillinge prüfen „kein Ziel vor seinem Bestehen“ — wer die Datei ändert, fährt alle UEMS-Tests · `uems-referenzunternehmen-die-eine-beispi.md`
