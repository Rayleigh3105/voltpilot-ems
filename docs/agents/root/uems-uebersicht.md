Diese Seite sammelt die Wegweiser-Einträge aller Bau-Pakete des Programms Unternehmens-Energiemanagement (UEMS), damit der Themen-Index von `AGENTS.md` nur EINE Zeile dafür trägt. Die Begriffe stehen im Glossar [`docs/fachmodell/README.md`](../../fachmodell/README.md), die bindenden Schnittstellen in [`docs/contracts/v2/README.md`](../../contracts/v2/README.md).

- **Bestandsschutz-Fingerabdruck in Migrationstests: `uems/Bestandsschutz` (Testquellen), nie `isEqualTo` auf der Tabellen-Map** — die Tests nehmen den ersten Fingerabdruck auf IHRER Fassung und migrieren danach bis zum neuesten Stand; jede SPÄTERE Migration mit neuer Tabelle stand darum als Unterschied da (`messstelle_formel_fassung` aus #706 machte drei Tests rot), und die alte Abhilfe — die neue Tabelle mit Namen ausnehmen — musste jedes Paket in allen älteren Tests wiederholen. `Bestandsschutz.fingerabdruck(db, ausnahmen)` misst jede Tabelle des Schemas (`LIKE`-Ausnahmen nur für die Tabellen des EIGENEN Pakets), `abweichungen(vorher, nachher)` meldet geänderten Inhalt einer bestehenden Tabelle, eine verschwundene Tabelle und eine NEUE Tabelle MIT Inhalt; eine neue LEERE Tabelle ist keine Abweichung. Dieselbe Unterscheidung eine Ebene tiefer: die Zeile zählt als jsonb-Objekt OHNE ihre SQL-NULL-Spalten (nicht `t::text`), eine spätere Spalte, die überall NULL ist, ändert nichts — eine mit Wert (auch per `DEFAULT`) ist eine Abweichung. `mutationsprobe(...)` beweist je Testklasse auf der echten Datenbank (zurückgerollte Transaktionen), dass eine geänderte Bestandszeile, eine gefüllte neue Tabelle und eine befüllte neue Spalte auffallen und eine leere Tabelle/Spalte nicht. Wer nur EINE Tabelle oder einen Ausschnitt misst (etwa die pünktlichen Rohwerte), nimmt `inhalt(db, tabelle, bedingung, args)` und beweist ihn mit `inhaltsprobe(...)` — nie ein eigenes `md5(string_agg(t::text …))`, das an einer später angehängten leeren Spalte rot wird. ⚠ Legt eine spätere Migration ihre Tabelle MIT Startzeile an (Laufzustand wie `messreihe_tag_lauf`), ist das eine Abweichung: die Tabelle mit Begründung in die Ausnahmen des älteren Tests, nie den Vergleich aufweichen · `../../../services/api/src/test/java/com/voltpilot/api/uems/Bestandsschutz.java`
