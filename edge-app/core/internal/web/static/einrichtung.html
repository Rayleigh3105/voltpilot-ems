VoltPilotBox einrichten

Diese Box einrichten

Geben Sie die Kennung dieser Box ein. Sie steht unten auf der Box und im VoltPilot-Portal beim Schritt „Box verbinden“.

Auf dieser Box gibt es den WLAN-Anschluss nicht.

Internet für Ihre Box

Wählen Sie Ihr WLAN. Die Box sieht nur Netze im 2,4-GHz-Band.

    Kein WLAN zu sehen. Prüfen Sie, ob Ihr Router ein 2,4-GHz-WLAN sendet, und suchen Sie erneut.

    Stecken Sie ein Netzwerkkabel von der Buchse „WAN“ der Box zu Ihrem Router. Die Box nimmt das Kabel von selbst; es hat immer Vorrang vor dem WLAN.
