# Lokale Login-Schriften

Inter für Fließtext, Inter Tight für Überschriften; dieselben Familien wie im Portal. Die Dateien werden lokal ausgeliefert, ohne Font-Anfrage an Dritte.

| Datei | Quelle / Stand |
|---|---|
| `inter-latin.woff2` | Google Fonts Inter v20, 23.08.2026 |
| `inter-tight-latin.woff2` | Google Fonts Inter Tight v9, 23.08.2026 |

Variable Gewichte 100–900, Untermenge `latin` einschließlich deutscher Umlaute und ß. Für zusätzliche Sprachen den benötigten Zeichensatz prüfen. `@font-face` steht in `../css/voltpilot.css`.

Lizenz: SIL Open Font License 1.1; [OFL.txt](OFL.txt) muss die Schriften bei Weitergabe begleiten.
